> **In short (English):** StarSeed OS is an open-source, decentralized *social operating system*: governance by direct democracy, education, culture, AI assistants and shared spaces, all in one place. It runs in any browser at [starseed-os.vercel.app](https://starseed-os.vercel.app) and as self-updating native apps for macOS, Windows, Linux and Android ([latest release](https://github.com/StarSeedSystem/starseed-system/releases/latest)). Built with Next.js 15, React 19, Supabase and Tauri 2. Licensed under AGPL-3.0. [**Full English README**](README.en.md).

## Cómo funciona

<img src="assets/readme/como-funciona.svg" alt="Diagrama de tres capas: Red y nodos, Mente digital, Apps del ecosistema" width="100%">

**Tres capas, un flujo:** Física (Cuerpo) → Red (Sistema Nervioso) → Mente Digital → Apps (Expresión)

1. **Capa 1 — La Red y los Nodos**  
   Infraestructura física descentralizada: Mesh LoRa (Meshtastic, cola P0–P3, duty cycle), Wi-Fi/TCP (daemon, serial, BLE, simulador), Syncthing/P2P (cifrado extremo a extremo, archivos, cerebros, memoria).

2. **Capa 2 — La Mente Digital**  
   Inteligencia soberana 1.58-bit: Astraura (motor ternario, Needle 3, router económico, Jev, 22–127 MB, 0,12 s), Exocórtex (propiedad del usuario, lealtad al usuario, privacidad ↔ transparencia), Malla Neural (auto-vínculo WebRTC ≥2 neuronas, faros, relay, federación).

3. **Capa 3 — Las Apps del Ecosistema**  
   StarSeed OS (SOSD, Trinity, Genesis), StarSeed Nexus (Portal, Biblioteca, Hub), StarSeed Café (Economía, Menú, Comunidad). Tres apps nativas, instalables, PWA, código abierto absoluto.

## Empezar en 1 minuto

### Web (sin instalar)
[Abrir https://starseed-os.vercel.app](https://starseed-os.vercel.app) → Funciona en cualquier navegador. Instalable como PWA.

### Instalar app nativa
[Ir a /instalar](https://starseed-os.vercel.app/instalar) → Detecta tu dispositivo y te da el archivo correcto.  
O descarga directo desde [la última release](https://github.com/StarSeedSystem/starseed-system/releases/latest).

**Primera apertura (macOS/Windows):** los binarios no están firmados aún.
- macOS: clic derecho → **Abrir** → **Abrir**
- Windows: SmartScreen → **Más información** → **Ejecutar de todas formas**

### Desarrollo local
```bash
git clone https://github.com/StarSeedSystem/starseed-system.git
cd starseed-system
npm install
cp .env.example .env.local   # rellena solo lo que necesites (Supabase mínimo)
npm run dev                  # http://localhost:9002
```

**Comprobaciones antes de proponer cambios:**
```bash
npm run typecheck   # TypeScript (tsc --noEmit)
npm test            # pruebas con Vitest
npm run build       # compilación de producción
```

**Apps nativas (requiere Rust ≥ 1.77.2 y Tauri CLI 2):**
```bash
cd native
cargo tauri build                    # StarSeed OS
cargo tauri build -c tauri.nexus.conf.json   # StarSeed Nexus
cargo tauri build -c tauri.cafe.conf.json    # StarSeed Café
```
Guía completa en [`native/README.md`](native/README.md).

## Principios

Toda función pasa este filtro ([detalle](memory/principles.md)):

- **Ontocracia** — Democracia directa, soberanía individual, voto delegado líquido, una persona una voz.
- **Ciberdelia** — Tecnología para expandir la conciencia, nunca para controlar. Estética cyberdélica + cristal líquido.
- **Transhumanismo Comunista** — Abundancia, procomún, automatización que libera. Código 100 % abierto.
- La persona es soberana sobre sus datos. Sin rastreo, publicidad ni pago para funciones democráticas.
- Moderación restaurativa, no punitiva. La estética eleva, no atrapa.

---

## Privacidad y seguridad

- **Tus datos son tuyos.** Cuenta privada; solo lo que publicas en un perfil es público. Supabase con políticas de acceso por fila (RLS).
- **Sin publicidad ni rastreadores de terceros.** Sin analítica comercial.
- **IA local primero.** Con el núcleo 1.58-bit en tu dispositivo, las consultas se resuelven allí. Claves de proveedores solo en servidor.
- **Permisos explícitos.** La app nativa pide permiso antes de usar terminal, archivos, notificaciones. Solo actualizaciones firmadas.
- **Núcleo intocable.** Ningún paquete compartido puede quitar la salida a Ajustes, la identidad soberana, los permisos visibles ni la integridad del voto.

¿Vulnerabilidad? No abras issue público: **Security → Report a vulnerability** en este repo (o pide canal privado sin detalles).
