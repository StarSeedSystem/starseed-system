# Genesis Contenedor

Plantilla de GitHub Actions para conectar un repositorio externo a StarSeed OS.

## Configuración
1. Copia este archivo a `.github/workflows/genesis.yml` en tu repositorio.
2. Añade el secreto `STARSEED_MOTOR_TOKEN` en los ajustes de tu repositorio (GitHub Actions -> Secrets).
3. Obtén tu token de tu instancia de Genesis.

## Límites
El uso está sujeto a los límites gratuitos de GitHub Actions: https://docs.github.com/es/actions/learn-github-actions/usage-limits-billing-and-administration
