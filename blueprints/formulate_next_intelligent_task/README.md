# Catálogo de Blueprints para `formulate_next_intelligent_task`

## Descripción

Este catálogo contiene todos los blueprints que `formulate_next_intelligent_task` del Director puede usar. Cada blueprint representa un estilo de formulación de tareas diferente.

## Uso

`formulate_next_intelligent_task` selecciona aleatoriamente un blueprint con `random.choice` y luego lo usa para generar el prompt de una tarea.

## Contenido del Blueprint

Cada blueprint es un archivo .md que documenta:
- Propósito y descripción
- Tipo de tarea
- Restricciones y límites
- Arquitectura y tecnologías
- Escenario / Contexto del Director

## Catálogo

- `0_brief.md` - Brief general del Director
- `1_task_gen_plugin.md` - Plugin de generación de tareas
- `2_agentes_ts_3_archivos.md` - Tareas con máximo 3 archivos
- `3_usuarios.md` - Plantilla de formulación de usuarios
- `4_impulsor.md` - Impulsor de formulación

## Integrantes

Creado por el Director para la gestión de tareas.
