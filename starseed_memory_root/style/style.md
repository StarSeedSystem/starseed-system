# 🎨 STYLE — Sistema de Diseño & Configuración de Cuenta (style.md)

> Lenguaje visual de StarSeed + preferencias de apariencia/configuración del usuario.

## Lenguaje visual
- **Tema:** "Crystal Liquid Glass" (vidrio líquido, profundidad, *sheen*, glows).
- **Trinity:** Zenith (cyan · arriba) · Anchor (rojo · abajo) · Horizon (verde · izquierda) · Logic (ámbar · derecha).
- **Tipografías:** Space Grotesk (headline) · Inter / Roboto / Outfit (cuerpo) · Source Code Pro (código).
- **Layout:** radios y espaciados fluidos (`clamp`), `backdrop-blur`, paleta por color (cyan/crimson/amber/emerald/purple/neutral).

## Configuración de apariencia (cuenta)
- Modo **oscuro** por defecto.
- Fondos animados globales seleccionables: Spline · Living · Materia Viva · Audiomorphic · WebGL.
- **Dock Trinidad** configurable: añadir/quitar/reordenar items (ver `src/components/layout/dock-config.ts`).
- Sensibilidad de bordes del perímetro Trinity ajustable.

## Preferencias de UI del usuario
- Idioma: **Español**.
- Interfaz limpia, sin ruido; **login-first**.
- Aurora con glow por voz; no abrir chat al inicio.
