# 🧠 starseed_memory_root — Índice del Memory Root (index.md)

> Conjunto **completo** de memorias StarSeed, organizado como **raíz + ramas** (carpetas).
> Portátil: se comparte/vincula a **cerebros**, **servidores** (internos / StarSeed / externos)
> y **computadoras virtuales en línea**, vía cualquier servicio/plugin/conexión como servidor+almacén.
> _El nombre del root lo elige el usuario: `<nombre>_memory_root`._

## Ramas (carpetas de memoria)

| Rama | Archivo(s) | Tipo | Qué guarda |
|---|---|---|---|
| `soul/` | `soul.md` | alma | identidad + contexto + **preferencias del usuario** |
| `ego/` | `ego.md` | aurora | configuración completa de **Aurora** |
| `skills/` | `skills.md` | skills | habilidades + **APIs** + **plugins** + instrucciones |
| `style/` | `style.md` | diseño | sistema de diseño + configuración de cuenta/UI |
| `memory/` | `memory.md` | memoria | hechos/estado (+ memoria profunda en `../memory/`) |
| `dream/` | `dream.md` | dream | visión + proceso Dream |
| `accounts/` | `accounts.md` | cuentas | registro (sin secretos en texto plano) |
| `tasks/` | `tasks.md`, `past_task.md` | tareas | activas + completadas |
| `logs/` | `logs.md` | logs | bitácora del sistema |

## Sistema
- `index.md` (este) · `sync.md` (vínculos & sincronización) · `memory.manifest.json` (manifiesto a detalle).
- Memoria profunda existente: `../memory/` (architecture · principles · glossary · roadmap · state) + `../CLAUDE.md`.

Destinos: 🧠 cerebros · 🖥️ servidores internos/StarSeed/externos · ☁️ VMs en línea · 🔌 cualquier servicio/plugin/conexión como **servidor + almacén** (de memorias, funcionamiento, configuraciones, opciones y sincronizaciones).
