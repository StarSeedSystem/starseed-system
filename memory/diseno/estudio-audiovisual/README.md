# Estudio audiovisual StarSeed (fuente de la skill)

Fuente de la skill `starseed-estudio-audiovisual` del plugin privado de Claude «starseed-estudio» (2026-10-19).
La usan Claude y el director de diseño: ADN y tokens con contrastes medidos, narrativa, mapa de herramientas,
formatos, licencias, perfil de diagramas y `scripts/comprobar_adn.py` (comprobador real de las pruebas p1–p8).

- `references/perfil-diagram-design-starseed.md` deriva de `references/style-guide.md` de
  cathrynlavery/diagram-design (MIT, aviso en `references/LICENSE-diagram-design.txt`).
- El símbolo está en `public/starseed-symbol.png`.
- Sistema de diseño en Claude: https://claude.ai/artifact/XGig1BviuZC1C1157GKxSL
